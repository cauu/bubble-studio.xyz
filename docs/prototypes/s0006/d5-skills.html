INSTALL ONE BY ONE

按需安装，各自独立

每个 Skill 都可以单独安装，复制命令到终端即可。

01可持续迭代协议

immutable-spec

让用户和 AI 围绕同一份 Spec 及其关联文档持续推进项目，每轮计划、决策、执行结果和验收证据都有记录可查。

$npx skills@latest add cauu/skills --skill immutable-spec
查看定义 ↗
02开发前检查

challenge

在开始开发前，先检查问题是否真实、方案是否过度复杂、关键假设是否成立，避免做错或做多。

$npx skills@latest add cauu/skills --skill challenge
查看定义 ↗
03代码设计

codebase-design

在写代码前先划清模块职责和交互方式，让复杂逻辑待在合适的位置，后续更容易修改和测试。

$npx skills@latest add cauu/skills --skill codebase-design
查看定义 ↗
04开发

tdd

围绕一个具体行为，先写一个会失败的测试，再写最少的代码让它通过，逐步完成开发。

$npx skills@latest add cauu/skills --skill tdd
查看定义 ↗
05代码审查

code-review

让三个相互隔离的 Reviewer 分别检查同一份代码，再核实并合并问题，最后交给人决定是否处理。

$npx skills@latest add cauu/skills --skill code-review
查看定义 ↗
06仓库导航

codebase-map

为代码仓库维护一份简明的导航地图，记录重要目录、模块职责和关键入口，方便人和 Agent 快速找到代码。

$npx skills@latest add cauu/skills --skill codebase-map
