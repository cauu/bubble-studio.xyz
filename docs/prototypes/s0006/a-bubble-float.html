质押即订阅

传统订阅模式要求用户定期付费。Pao Studio 尝试基于 Cardano 原生质押机制，建立一种新的订阅方式。 用户将 ADA 委托给 Pao Pool，无需额外付费、锁仓或托管，照常获得质押奖励。矿池运营收入用于维持 Pao Pool 运行，并支持 Pao Studio 提供相应的内容和产品服务。
