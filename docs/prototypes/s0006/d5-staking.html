CARDANO 质押 · PAO POOL

从 Pao Pool 开始理解 Cardano 质押

Cardano 质押允许你把 ADA 对应的质押权委托给矿池，而无需转出或锁定 ADA。资产仍由你的钱包控制。奖励取决于协议周期和矿池表现，并不保证。

01
运作机制

Cardano 委托实际改变了什么

委托把钱包地址对应的质押权与一个矿池关联起来，不会把 ADA 所有权转给矿池运营者。

ADA 仍在你的钱包中

委托通过 stake credential 记录。支付资金仍由你控制并可以使用。进行委托时，不要直接向矿池运营者转账 ADA。

质押权参与网络共识

协议会把你的委托量计入矿池。矿池可能被选中生产区块，帮助 Cardano 处理交易并维护账本。

运营者负责运行节点

矿池运营者维护在线基础设施、监控节点，并在被选中时生产区块。委托者无需亲自运行这些设施也能参与。

02
奖励与时间

奖励遵循协议，不是一项承诺

新委托需要跨多个 epoch 经历质押快照、区块生产和奖励计算，不会在确认委托后立即开始发放。

  1. EPOCH N+0

    质押权进入快照

    Cardano 在 epoch 边界记录 stake。新委托需要先出现在协议用于后续区块选择的快照中。

  2. EPOCH N+1

    矿池可能生产区块

    获得区块机会与委托量有关，实际结果也取决于协议选择，以及矿池被选中时是否正常履职。

  3. EPOCH N+2

    计算并分配奖励

    矿池获得奖励后，协议会按矿池固定成本和 margin 等规则，自动计算并分配委托者份额。

奖励并不保证。矿池可能出现没有奖励的 epoch，历史结果或估算 APY 也不能预测未来回报。

04
委托指南

如何把 ADA 委托给 Pao Pool

不同钱包的具体界面可能不同。请始终在自己的兼容 Cardano 钱包中操作，并在确认前核验矿池身份。

  1. 打开矿池页面

    打开 Cexplorer 的 PAO 页面，或进入兼容 Cardano 钱包中的 stake pool 目录。

  2. 核对 ticker 与 pool ID

    搜索 PAO，并把完整 pool ID 与本页显示的 ID 对照。只看 ticker 不足以确认身份。

  3. 在钱包中选择委托

    使用钱包提供的 delegation 操作。你不需要向 Pao Studio 或 Pao Pool 转账 ADA。

  4. 检查并确认

    签署委托交易前，检查钱包显示的矿池、网络费，以及首次注册 stake credential 时可能出现的可退还 deposit。

  5. 核验委托结果

    在钱包或浏览器中检查当前委托状态。奖励按协议周期开始，并不保证金额。

05
选择之前

评估 Cardano 矿池时要看什么

没有一个指标能够证明某个矿池一定是最佳选择。除了协议参数，还应检查运营者的历史、目的与沟通。

固定成本与 margin

这些参数会影响矿池奖励如何在运营成本、运营者和委托者之间分配。

Saturation

矿池超过协议 saturation 点后，每单位 ADA 的奖励可能下降，以此鼓励质押权分散。

区块生产记录

检查矿池长期是否完成了被分配的区块，同时记住较短周期的结果可能受随机性影响。

运营透明度

检查稳定身份、公开沟通、基础设施连续性、最新 metadata，以及运营矿池的明确目的。

06
直接回答

Cardano 质押常见问题

委托给 Pao Pool 会转出或锁定我的 ADA 吗？

不会。Cardano 委托分配的是质押权，ADA 仍由你的钱包控制并可以使用。

Cardano 质押奖励有保证吗？

没有。奖励取决于协议规则、矿池获得的委托量和矿池表现，矿池可能出现没有奖励的 epoch。

新委托什么时候开始获得奖励？

Cardano 会跨多个 epoch 使用 stake snapshot，因此奖励不会立即开始。请在钱包或浏览器中查看当前委托与奖励时间线。

之后可以更换矿池吗？

可以。你可以通过兼容钱包重新委托。重新委托只改变质押权指向的矿池，不会把 ADA 转给矿池。

委托给 Pao Pool 会支持什么？

矿池运营收入帮助 Pao Studio 维护基础设施并开发内容和产品。会员权益是 Pao Studio 额外提供的服务，不是 Cardano 协议奖励。
