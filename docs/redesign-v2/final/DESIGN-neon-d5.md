# DESIGN · Neon D5

S0006 s6-02 冻结的站点视觉与动效规范。取代 `DESIGN-bubble-light.md` 作为站点实现依据；Bubble-light 文档保留为历史记录。原型见 `docs/prototypes/s0006/d5-*.html`。

## 1. 视觉

### 1.1 色彩

| Token               | 值                      | 用途                                           |
| ------------------- | ----------------------- | ---------------------------------------------- |
| `--void`            | `#0a0910`               | 页面底色（纯黑基调，不交替浅色或整块彩色区块） |
| `--void-2`          | `#13111c`               | 卡片、面板                                     |
| `--term`            | `#05040a`               | 终端框、委托栏                                 |
| `--line`            | `rgba(244,242,255,.12)` | 分割线、卡片描边                               |
| `--fg`              | `#f4f2ff`               | 标题与强调文字                                 |
| `--fg-dim`          | `rgba(244,242,255,.62)` | 正文辅助文字（不用于 14px 以下正文）           |
| `--mag` / `--mag-d` | `#fc5ff6` / `#c60a76`   | Logo P                                         |
| `--cy` / `--cy-d`   | `#2ffff3` / `#078cbe`   | Logo A，主按钮                                 |
| `--yel` / `--yel-d` | `#fff590` / `#d9b201`   | Logo O，关键词高亮                             |
| `--grn` / `--grn-d` | `#31ee6b` / `#079f1b`   | 终端字、状态                                   |
| `--pur` / `--pur-d` | `#c141f2` / `#590ac6`   | 辅助色                                         |

- 霓虹色只作强调：标签、编号、关键词色块、章节分割线、几何图形；亮色块上一律使用 `--void` 文字。
- 收尾区「LET'S BUILD.」使用描边 + 品红文字，不使用整块品红背景。

### 1.2 字体

- 正文与标题：Inter + AlibabaPuHuiTi（CJK）。
- 等宽：JetBrains Mono，只用于标签、路径、编号、数据、终端框、按钮文字。

### 1.3 版式

- 阅读栏宽 1180px，左边缘与首页 Hero 文案对齐（`--pad: max(20px, calc((100vw - 1180px) / 2 + 24px))`）。
- 页头规则：终端路径 + 短标题（关键词色块高亮）+ 最多一句说明；不放英文眉标与数据行。
- 章节分割：「闸门」= 霓虹线（2px，带光晕）+ 描边编号（clamp 48–96px）+ 英文小标 + 标题（clamp 28–52px）。
- 卡片：`--void-2` 底、1px `--line` 描边、角标描边（hover 放大）；不使用阴影卡片。
- 按钮：切角（`clip-path` 12px）；主按钮 `--cy` 底，次按钮 1.5px 描边。
- 背景：全局静态扫描线纹理 + 固定 canvas 粒子层。

## 2. 动效

| 类别       | 参数                                                                                                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 开场       | 每会话一次（`sessionStorage`），约 3s：P 滑入 620ms / A 落下 560ms / O 弹出 640ms，STUDIO 打字，1050ms 共享元素过渡到 Hero 色块；点击、按键、滚轮、触摸可跳过 |
| 进入视口   | `opacity` + `translate` 36–40px，800–1000ms，`cubic-bezier(.2,.9,.2,1)`，每项错开 60–90ms                                                                     |
| 章节分割线 | `scaleX` 0→1，1200ms，`cubic-bezier(.76,0,.24,1)`                                                                                                             |
| 视差       | 仅 ≥901px 桌面；元素位移系数 ≤ 0.1（Hero 色块指针视差 18–44px），测量时扣除自身位移                                                                           |
| 故障字     | 仅 Hero 入场与悬停触发，每 1.5s 最多一次（WCAG 2.3.1）                                                                                                        |
| 粒子       | 桌面 42 / 手机 18，标签页隐藏时暂停                                                                                                                           |
| 持续循环   | 仅扫描线（静态）、光标闪烁、live 点、跑马灯（随滚动加速，离屏暂停）                                                                                           |

- 只动画 `transform`、`opacity`、`translate`、`clip-path`（开场）与 `filter`（开场闪烁）。
- `prefers-reduced-motion: reduce`：不播开场、无视差、无粒子、内容直接可见。
- 无 JS：所有内容可见。
